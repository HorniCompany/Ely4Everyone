# Вход напрямую через Ely.by

Вход теперь идёт **напрямую через Ely.by**, без посредников! 🎉

### Что нового
- **Прямой вход в Ely.by.** Мод больше не ходит через сервер horni.cc: жмёшь «Войти через Ely.by», браузер сам открывается на странице Ely.by с уже вписанным кодом, выбираешь аккаунт, нажимаешь «Разрешить», и игра сама подхватывает вход.
- **Можно подтвердить с телефона.** Код показан прямо в игре: если браузер не открылся, зайди на account.ely.by/code и введи его.
- **Твои Ely-токены больше не хранятся на чужом сервере** и не зависят от того, работает ли horni.cc.
- **Скины приходят с подписью Ely** (раньше подпись терялась по дороге).
- Экран входа стал проще: без выбора серверов входа, а сессия показывается как «активна», а не обратным отсчётом на тысячи дней.
- Новые иконка и баннер, перерисованные в вектор.

### Обновление
Просто замени JAR-файл в папке `mods`. Если ты уже входил через старую версию, вход сохранится и продолжит работать. Новый вход через Ely.by можно сделать в любой момент кнопкой «Выйти» и затем «Войти через Ely.by».

### Для владельцев серверов
`ely4everyone-velocity-plugin` в этом релизе:
- Ely-игроки распознаются раньше и без лишнего запроса к Mojang, а запросы к Mojang идут через `api.minecraftservices.com`;
- вход через встроенный сервер авторизации стал безопаснее (loopback + PKCE);
- ⚠️ по умолчанию `allow_legacy_poll_login=false`: игроки со **старым** модом 0.1.0-alpha не смогут заново войти через твой сервер авторизации и увидят просьбу обновиться. Новому моду сервер авторизации вообще не нужен.
