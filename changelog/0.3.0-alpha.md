# Все версии от 1.21.11 до 26.3, английский язык и починенные скины

### Новые версии Minecraft
Теперь мод есть для **1.21.11, 26.1.2, 26.2 и 26.3**. Под каждую версию свой файл, бери тот, что подходит к твоей игре:

| Minecraft | Файл | Java |
|---|---|---|
| 26.3 | `ely4everyone-mod-0.3.0-alpha+26.3.jar` | 25 |
| 26.2 | `ely4everyone-mod-0.3.0-alpha+26.2.jar` | 25 |
| 26.1.2 | `ely4everyone-mod-0.3.0-alpha+26.1.2.jar` | 25 |
| 1.21.11 | `ely4everyone-mod-0.3.0-alpha+1.21.11.jar` | 21 |

### Английский язык
Мод говорит по-русски, если игра на русском, и по-английски на всех остальных языках.

### Исправлено
- **Твой собственный скин был дефолтным вместо скина с Ely.by** (с версии 0.2.0, особенно заметно в одиночной игре). Мод неправильно читал ответ Ely.by и сохранял вход без скина. Теперь скин подтягивается сам при запуске игры, входить заново не нужно.
- **Вылет игры из-за ников с пробелом, цветовыми кодами `§` или слешем** (так часто называют NPC на серверах). Такие ники больше не ищутся на Ely.by, а любая ошибка при загрузке скина откатывается к обычному скину вместо вылета.

### Изменено
- Страница входа Ely.by открывается в браузере самим модом (в 26.3 игра убрала свой способ).
- Убран старый код входа через промежуточный сервер. Мод больше не создаёт `config/ely4everyone.properties`, старый файл можно удалить.
- Мод только клиентский. Плагин для Velocity больше не прикладывается к релизам.

### Обновление
Замени старый jar в папке `mods` на файл под свою версию игры. Вход в Ely.by сохранится.

### Как проверено
Каждая версия проходит автоматические тесты в настоящей игре: кнопка и экран входа на английском и русском, Ely-скины других игроков по нику, ники с пробелом без вылета, одиночный мир и сервер. Вход через Ely.by и свой скин дополнительно проверены вручную на 1.21.11 и 26.1.2.

# All versions from 1.21.11 to 26.3, English and fixed skins

### New Minecraft versions
The mod now exists for **1.21.11, 26.1.2, 26.2 and 26.3**. Each version has its own file, pick the one for your game:

| Minecraft | File | Java |
|---|---|---|
| 26.3 | `ely4everyone-mod-0.3.0-alpha+26.3.jar` | 25 |
| 26.2 | `ely4everyone-mod-0.3.0-alpha+26.2.jar` | 25 |
| 26.1.2 | `ely4everyone-mod-0.3.0-alpha+26.1.2.jar` | 25 |
| 1.21.11 | `ely4everyone-mod-0.3.0-alpha+1.21.11.jar` | 21 |

### English
The mod speaks Russian when the game is set to Russian and English for every other language.

### Fixed
- **Your own skin showed as a default one instead of your Ely.by skin** (since 0.2.0, most visible in singleplayer). The mod misread the Ely.by reply and saved the login without the skin. It now fetches your skin when the game starts, no new login needed.
- **The game crashed on nicknames with spaces, `§` colour codes or slashes** (common for NPCs on servers). Such names are no longer looked up on Ely.by, and any error while loading a skin falls back to the usual skin instead of crashing.

### Changed
- The Ely.by login page is opened in the browser by the mod itself (26.3 removed the game's way of doing it).
- The old login through an intermediate server is gone. The mod no longer creates `config/ely4everyone.properties`; an old one can be deleted.
- The mod is client-side only. The Velocity plugin is no longer part of the releases.

### Updating
Replace the old jar in your `mods` folder with the file for your Minecraft version. Your Ely.by login is kept.

### How it was checked
Every version passes automated tests in the real game: the title screen button and the Ely screen in English and Russian, other players' Ely.by skins by nickname, nicknames with spaces without a crash, a singleplayer world and a server. Logging in with Ely.by and your own skin were also checked by hand on 1.21.11 and 26.1.2.
