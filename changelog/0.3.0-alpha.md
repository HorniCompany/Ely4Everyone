# Все версии от 1.21.11 до 26.3, английский язык и починенные скины

### Новые версии Minecraft
Теперь мод есть для **1.21.11, 26.1.2, 26.2 и 26.3**. Под каждую версию свой файл, бери тот, что подходит к твоей игре:

| Minecraft | Файл | Java |
|---|---|---|
| 26.3 | `ely4everyone-mod-0.3.0-alpha+26.3.jar` | 25 |
| 26.2 | `ely4everyone-mod-0.3.0-alpha+26.2.jar` | 25 |
| 26.1.2 | `ely4everyone-mod-0.3.0-alpha+26.1.2.jar` | 25 |
| 1.21.11 | `ely4everyone-mod-0.3.0-alpha+1.21.11.jar` | 21 |

### Английский язык
Мод говорит по-русски, если игра на русском, и по-английски на всех остальных языках.

### Исправлено
- **Твой собственный скин был дефолтным вместо скина с Ely.by** (с версии 0.2.0, особенно заметно в одиночной игре). Мод неправильно читал ответ Ely.by и сохранял вход без скина. Теперь скин подтягивается сам при запуске игры, входить заново не нужно.
- **Вылет игры из-за ников с пробелом, цветовыми кодами `§` или слешем** (так часто называют NPC на серверах). Такие ники больше не ищутся на Ely.by, а любая ошибка при загрузке скина откатывается к обычному скину вместо вылета.

### Изменено
- Страница входа Ely.by открывается в браузере самим модом (в 26.3 игра убрала свой способ).
- Убран старый код входа через промежуточный сервер. Мод больше не создаёт `config/ely4everyone.properties`, старый файл можно удалить.
- Мод только клиентский. Плагин для Velocity больше не прикладывается к релизам.

### Обновление
Замени старый jar в папке `mods` на файл под свою версию игры. Вход в Ely.by сохранится.

### Как проверено
Каждая версия проходит автоматические тесты в настоящей игре: кнопка и экран входа на английском и русском, Ely-скины других игроков по нику, ники с пробелом без вылета, одиночный мир и сервер. Вход через Ely.by и свой скин дополнительно проверены вручную на 1.21.11 и 26.1.2.

---

**Minecraft 1.21.11, 26.1.2, 26.2 and 26.3**, one file per version (see the table). **English** for every game language except Russian. **Fixed:** your own skin showed as a default one since 0.2.0 (the Ely.by reply was misread at login; the mod now fetches your skin at start, no new login needed), and the game crashed on nicknames with spaces, `§` colour codes or slashes (common for NPCs). The Ely.by login page now opens through the mod itself. The old auth-host code is gone, `config/ely4everyone.properties` is no longer created and can be deleted. The mod is client-side only; the Velocity plugin is no longer part of the releases. Update by replacing the jar with the one for your Minecraft version; your Ely.by login is kept.
